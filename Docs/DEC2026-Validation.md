## 本次行為

- 精確辨識 `ESC[?2026h`／`ESC[?2026l`，不送入舊數值指令處理器，也不回覆封包。
- 每條連線獨立保存可見文字列與顏色屬性快照，繼續接收及解析資料；同步中由重畫流程顯示快照。
- 結束指令後釋放快照並要求重畫。游標與閃爍文字不在同步中顯示接收中的內容。
- 開始重複出現不累加巢狀層數，也不延長目前的等待期限。
- 逾時門檻 2 秒，由接收事件及既有 1 秒計時器檢查；無新資料時通常在 2～3 秒內解除顯示等待。
  UI 執行緒繁忙時仍可能較晚處理，不是硬即時保證。
- 逾時只恢復畫面，不允許文章複製繼續判定完成；收到真正結束指令或重新建立連線才解除保護。
- 更改終端機緩衝區尺寸時放棄舊尺寸快照，採相同保守複製保護；僅調整視窗／字體大小可繼續重畫快照。
- 同步中純文字／帶色選取複製、選取搜尋／翻譯與超連結命中暫停，避免操作看不到的新內容；結束後恢復。
- 本機 ANSI 編輯器不啟用同步等待。未送同步指令的站台維持一般顯示。

不修改 WSS／WinHTTP、不新增套件或設定 UI。原始資料觸發器仍採原本處理方式，**不保證它等到完整畫面才觸發**。
本階段不處理合併多參數私有模式（例如 `?2026;1000h`）或狀態查詢 `?2026$p`；它們仍安全略過。
同步只改善呈現／擷取時機，不會加速網路；逾時或尺寸變更後允許呈現部分畫面是避免永久停住的降級行為。
不宣稱任意輸出都具完整交易一致性，亦未重寫文章下載器或觸發器。

### 1. 一般使用回歸

關閉其他 PCMan，一次只開一個組態，直接使用原目錄內的程式，不要只複製 EXE：

- `D:\Codes\pcman-windows2\Lite\Debug\PCMan\PCMan.exe`
- `D:\Codes\pcman-windows2\Lite\Release\PCMan\PCMan.exe`

分別登入平常的 PTT WSS，檢查列表、文章上下頁、返回列表、短／長文章複製、帶色複製。
檢查縮放視窗、切換分頁、閃爍文字與游標恢復；沒有永久停格、遺漏內容或新增控制碼殘字即可。
若下載停住，可按取消；請回報是否發生逾時／斷線，不要當成已成功完成。
一般網路正常時可能看不出視覺差異，因此仍建議進行下面的本機測試。

### 2. 可重現的本機慢速輸出測試

這不是 PTT，也不需要帳密。工具只監聽 `127.0.0.1`，不連外、不記錄客戶端輸入，結束後釋放連接埠。
**請使用新的測試連線，不要沿用含自動登入、巨集或觸發器的站台設定；不要輸入任何帳密。**

1. 在專案根目錄的 PowerShell 執行：

   ```powershell
   powershell -NoProfile -File Tests/Start-SyncOutputFixture.ps1
   ```

2. 在 60 秒內，用 PCMan 建立 Telnet 連線：`telnet://127.0.0.1:22326`（不是 WSS）。
3. 依 PowerShell 的 A～E 提示按 Enter，再切回 PCMan 觀察：

| 情境 | 預期 |
| --- | --- |
| A：沒有同步指令 | 約 1 秒內會看到上半 NEW、下半 OLD，之後都變 NEW；這是對照組 |
| B：有同步指令，重複三次 | 先保留整頁 OLD，接著整批 NEW；不應像 A 出現中間混合畫面 |
| C：刻意不送結束 | 先 OLD，約 2～3 秒後允許顯示半更新內容；4.5 秒後補送資料與結束，恢復正常，不永久停住 |
| D：同步期間縮放／切換分頁 | 舊快照仍可重畫，結束後更新；縮放視窗與修改終端機列欄設定不是同一件事，這裡只測視窗縮放 |
| E：同步中斷線 | 連線結束後解除顯示等待，不保留永久凍結狀態；重新執行工具後可再連線測試 |

4. 完成後關閉測試分頁與腳本；另一組態請重新執行工具。若不想測完，可停止腳本，連線即中止。
5. 若腳本被系統執行原則／防毒阻擋，請提供錯誤訊息，不需為此停用安全軟體。

此腳本測的是實際接收與重畫整合，不含完整 BBS、WSS、文章底列或登入流程。
新版本與舊版本可分別測 B 作比較，但不要同時執行，以免單一執行個體機制切回另一版本。
