# SGR 66 彩圖匯出／貼上：實作與驗收

日期：2026-10-17。範圍：PCMan LITE；已實作，待人工驗收及提交。
本輪不自動登入 PTT、發表文章、操作剪貼簿或啟動 GUI。

## 使用方式與格式選擇

「ANSI 編輯」選單末端新增三個全域選項，影響彩色複製、彩色文章下載、ANSI 存檔及彩色貼上：

| 選項 | 行為 |
| --- | --- |
| 自動（預設） | PTT／PTT2 及其子網域、本機 ANSI 編輯器使用 SGR 66；其他 BBS 保留傳統格式 |
| 傳統 Big5 格式 | 匯出保留舊式半字色碼；貼上不進行 SGR 66 正規化 |
| SGR 66 相容格式 | 明確使用新格式，亦可供其他已支援 SGR 66 的 BBS／本機測試使用 |

設定以 `[BBS] ansi_output_format` 儲存：`0` 自動、`1` 傳統、`2` SGR 66；舊設定檔缺少欄位時預設自動，非法值按自動解釋。
此選項是整個程式共用，不是每個分頁各自獨立；更換輸出目標時請確認模式。
此選項不會關閉 SGR 66 接收；選傳統輸出仍能在 Big5 編輯器讀取新格式。
目前只有 Big5／UAO（CP950）及 UTF-8 路徑啟用新匯出；其他碼頁保留舊路徑。

## 實作行為

- [Sgr66.h](../Lite/Sgr66.h) 集中處理來源字元邊界、SGR 66 序列化、舊式貼上轉換與一次性左半屬性。
  彩色選取及整篇文章共用匯出方法；沒有另複製一份貼上用的半字格式規則。
- Big5 左右半字屬性不同時，先輸出一段 `ESC[左屬性;66;右屬性m`，再輸出完整的兩個 Big5 位元組。
  支援前景、背景、高亮度與閃爍，屬性完整重設後再指定，避免右半部重設破壞左半部。
- 接收 66 時保存當時屬性，只供下一個可列印位元組使用；後續參數仍修改正常屬性。
  因此 `ESC[1;37;66;33m中` 的左半白、右半黃，下一個字回到正常的黃色屬性。
  ASCII 也消耗一次保存屬性；CR／LF／TAB、取消、已分派的非 SGR 控制指令與連線重設會清除它。
- Big5 ANSI 編輯器及 Big5 連線可讀回雙色。UTF-8 接收維持公告允許的單色降級，沒有重寫終端機的位元組／顯示欄寬模型。
  UTF-8 匯出確保有效多位元組字元中不插入色碼，同一字元使用其首位元組的屬性，不宣稱支援 UTF-8 半字雙色。
- 新格式的選取按完整列判斷字界，只選到半個 Big5／UTF-8 字元時略過該不完整字元，不擴大輸出未選取內容。
  正常／反向／矩形選取及多列均受相同規則保護；尾端無背景空白仍依既有政策省略。
- Big5 彩色貼上在既有 ESC 替換之前，將有效 Big5 兩個位元組之間的完整數值 SGR 移至字元之前並加上 66。
  已是新格式的內容不重複改寫；過多連續 SGR 不合併成超過解析上限的單一指令。
  未知／私有／不完整色碼及不合法 Big5 配對不猜測修復；OSC／DCS／PM／APC／SOS 隱藏內容保持原樣。
- 「從檔案貼上」遇到 ANSI 色碼，也進入同一彩色貼上流程；純文字仍走既有傳送方法。
  保留原本的 ESC→站台指定控制鍵（預設 Ctrl-U）及貼上期間停用自動折行，再恢復設定。
- 不自動猜測 ANSI 檔或剪貼簿的來源碼頁、不轉換圖中文字編碼；來源與當前碼頁需一致。
  不處理已先替換為 Ctrl-U 的舊式半字色碼，亦不把既存 SGR 66 貼上內容反向改為舊格式。
  匯出不新增 OSC 8 隱藏目標，仍沿用既有可見文字／顏色政策。
- 另補文章／選取空白列裁切與舊式矩形中間列的邊界檢查，避免向列首之前或列尾之後讀取；未變更個人設定檔或 CP950 `.rc` 檔案編碼。

## 人工離線驗收

```powershell
powershell -NoProfile -File Tests/New-Sgr66VisualFixture.ps1
```

產生 `Tests/fixtures/Sgr66Compatibility.ans`、`LegacySplitPicture.ans`、`Sgr66Picture.ans`；皆為 CP950，僅供本機測試。

1. 一次只執行一個組態的 PCMan，以 Big5／UAO 開啟 `Sgr66Compatibility.ans`；此檔載入時暫用覆寫模式，末尾恢復插入模式。
2. 第 3 行中文字左亮白、右亮黃；第 4 行左亮白、右不亮紅。
3. 第 5 行第一個字左紅右綠，第二個字全綠，確認 66 不延伸到第二個字。
4. 第 6 行左半為亮白／藍底／閃爍，右半為不亮紅／黃底／不閃爍；第 7 行 X 紅、Y 綠。
5. 第 8 行舊式半字色碼與第 3 行新式雙色相同；第 9 行紅底空白保留；第 10 行回到正常色。
6. 選「SGR 66 相容格式」，彩色複製前述各行並貼到另一個 ANSI 編輯器分頁；雙色不得變成整字單色。
   同時測正常、反向、矩形及刻意只選到半個中文字；後者應略過不完整字元，不帶出未選取的半字。
7. 以新檔名「另存新檔」，關閉並重開檔案，檢查相同文字與雙色；不得覆寫原 fixture。
   切成「傳統 Big5 格式」再另存另一個檔案，確認舊格式仍可讀回。
8. 重啟程式，確認選單輸出格式設定會保存；切回自動，確認本機編輯器用新格式，其他 BBS 不被強制切換。
9. Debug／Release 分別執行。原本兩個 OSC 驗收腳本亦須回歸；不要將整張含清畫面／游標定位的 fixture 貼至公開 BBS。

## 本機接收／貼上驗收

```powershell
powershell -NoProfile -File Tests/Start-Sgr66Fixture.ps1
```

1. 60 秒內建立新的 `telnet://127.0.0.1:22366` 測試連線，使用 Big5。不要使用含帳密、自動登入、巨集或觸發器的既存站台設定。
2. A（接收顯示）：檢查逐位元組送出的雙色、下一字不沿用左色；這一步不需要貼上，輸出選「傳統 Big5 格式」也不影響接收。
   B（同步重畫）：依 PowerShell Enter 提示驗證 OLD 紅／綠快照，同步結束才更新成 NEW 藍／黃，
   不應出現一半舊色、一半新色的混合畫面。A／B 的畫面結果仍由使用者判讀，不由腳本自動判定。
3. C 是另一項「手動貼上」，不會把前面的接收畫面自動送回。若只測 A／B，可在 C 輸入 `S`，記錄為 `SKIP C` 而非通過；`Q` 則結束測試。
   要驗 C，先將全域模式設為「SGR 66 相容格式」（localhost 自動模式刻意維持傳統），
   在 ANSI 編輯器開啟 `LegacySplitPicture.ans`、選取完整「中 PICTURE」，使用「複製（包含 ANSI 彩色）」後貼到本機測試連線。
   連線畫面不回顯貼上內容；回 PowerShell 按 Enter，腳本使用最長 2 秒接收視窗，等待分段資料後才檢查。
   正常應顯示 `PASS C`；不會輸出或保存貼上內容，只顯示長度與條件是否成立。
   未貼上／只有協商、缺少 SGR 66、缺少指定中文字、不完整資料及舊式半字切斷會分別提示，保留連線讓使用者重新完整貼上後重試，或輸入 `S` 略過。
4. 若要另驗「從檔案貼上」，重新執行腳本，在同一步改選 `LegacySplitPicture.ans`；有需要時在檔案對話框選所有檔案。
   亦可重跑後改貼 `Sgr66Picture.ans`，確認已是新格式也通過。
5. D：最後以未消耗的 SGR 66 狀態斷線，重跑並重連，初始標題應為正常色，不沿用舊左色；C 略過後仍可執行 D。完成後關閉分頁與腳本。
6. 使用平常的 PTT 連線回歸瀏覽與純文字／彩色複製。發表／貼回站台涉及使用者內容，
   請僅在自己可控的草稿／私人測試位置操作；不以「一般瀏覽正常」替代彩圖輸入驗收。
